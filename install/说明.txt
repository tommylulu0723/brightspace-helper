课程助手 · 安装说明（装一次，以后自动热更新）

Windows：双击「Windows-一键安装课程助手.bat」，会打开安装窗口：
  1. 选择安装位置（默认 D 盘等非系统盘的 CourseHelper，可以点"浏览…"换）
  2. 点"安装"，等进度条走完（第一次会顺便装 Git，可能弹一次确认框，点"是"）
  3. 完成页点"打开 Chrome 扩展程序页面"，按提示点 3 下
  - 如果弹出蓝色的"Windows 已保护你的电脑"：点"更多信息" → "仍要运行"

Mac：双击「Mac-一键安装课程助手.command」，会弹出窗口，可以点"更改位置…"
  - 如果提示"无法打开"：右键这个文件 → 打开 → 打开

在 Chrome 里点 3 下（只需要一次）：
  1. 打开右上角「开发者模式」
  2. 点「加载已解压的扩展程序」
  3. 在窗口里粘贴路径（安装程序已经复制好：Windows 在地址栏 Ctrl+V；Mac 按 Cmd+Shift+G 再 Cmd+V），回车，选择文件夹

第一次打开插件：注册账号（First name / Last name 必须和 Brightspace 上的一致，邮箱用来收截止提醒），
再登录 Brightspace，插件会自动核对姓名，通过后就能用了。

手机 / iPad：用浏览器打开插件「设置 → 账号」里的"打开手机版"，登录同一个账号，
再"添加到主屏幕"，用起来像 App。

卸载：双击「Windows-卸载课程助手.bat」或「Mac-卸载课程助手.command」，再在 Chrome 扩展程序页面点「移除」。

以后有新版本，插件会弹出「检测到更新」，点「立即更新」即可，不用重装。
只支持 NYU Brightspace。
